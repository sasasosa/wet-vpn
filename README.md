# WET VPN — Android starter

This repository is an **Android UI starter**, not a working VPN client yet.

Included:
- Native Android app using Kotlin and Jetpack Compose
- Black/yellow WET VPN-inspired interface
- GitHub Actions workflow that builds a debug APK

Not included yet:
- VPN tunnel engine
- Subscription URL parsing/import
- Authentication, billing, account/device management

Those parts require the VPN service's documented subscription format/API and permission to integrate a compatible VPN engine. Do not put private subscription URLs, tokens, or credentials in this repository.

## Build
Open this project in Android Studio, or upload it to GitHub and let the included Actions workflow build it.
